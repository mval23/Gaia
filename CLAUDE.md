# Gaia

A kind planner: tasks, time-blocking, goals and gentle habits. The README's
"Conventions that keep Gaia kind" section is the house rulebook. Read it before
changing anything a user sees.

- **What's planned next:** [`docs/plans.md`](docs/plans.md) has the roadmap, the
  data model additions, the words to use, and what is deliberately left out. The
  illustrated version for people is `docs/plans.html`. Update both together.
  `plans.html` is also built into the app and shown at `/plans` ("What's coming"
  in the account menu), so keep it self-contained and working inside an iframe.
- Commands: `npm run dev` (port 5173), `npm test`, `npm run build`.
